NOVA VPN — Android-клиент на Flutter + sing-box

В ЭТОМ ПРОЕКТЕ УЖЕ РЕАЛИЗОВАНО:
- импорт одиночных ссылок и URL подписок;
- список импортированных серверов;
- выбор сервера;
- запуск/остановка настоящего VPN через sing-box VpnService;
- поддержка протоколов, которые поддерживает sing-box (например VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard).

ЧТО НУЖНО ДЛЯ РАБОТЫ:
- Нужна действующая ссылка сервера или подписки от провайдера. Пустое приложение само VPN-сервер не создаёт.
- Этот проект НЕ содержит Telegram-бота, платёжную систему или сервер проверки платных ключей.
- Старый OpenVPN .ovpn файл не является ссылкой VLESS/VMess и не импортируется этим экраном как share-link.
- Не публикуй приватные ссылки, пароли, UUID и ключи в открытом GitHub.

СБОРКА:
1. Создай Flutter-проект командой `flutter create .` в корне (если Android-папка неполная).
2. `flutter pub get`
3. `flutter build apk --release`

Либо загрузи проект в GitHub и запусти Actions → Build NOVA VPN APK.
Требуются Flutter SDK, Android SDK и доступ к интернету при первой сборке (скачивается libbox).
